# SplitEasy

A small full-stack expense splitter built with Codex for AI Dev Tools Zoomcamp 2026 Homework 2.

## Backend

```bash
cd backend
uv sync
uv run uvicorn app.main:app --reload
```

The API runs at `http://localhost:8000`.

## Frontend

In another terminal:

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173`.

## Tests

```bash
cd backend
uv run pytest
```
