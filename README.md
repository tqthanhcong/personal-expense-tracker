# Personal Expense Tracker

Django application created with Codex for DataTalksClub AI Dev Tools Zoomcamp 2026 Homework 1.

## Run locally

```bash
uv sync
uv run python manage.py migrate
uv run python manage.py runserver
```

Open http://127.0.0.1:8000/.

## Run tests

```bash
uv run python manage.py test
```

## Homework answers

1. Coding agent: Codex in ChatGPT Work.
2. Features: add an expense; view all expenses; filter by category; display the total amount.
3. File edited to include the app: `settings.py`.
4. Task 1: Create the Django project and expenses app.
5. Development server: `uv run python manage.py runserver`.
